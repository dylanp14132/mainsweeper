# Mainsweeper


A version of minesweeper using SMFL, built entirely in the main function (aside from preprocessor directives). 
The project was part of a class assignment on writing clean and scalable code.

## Configuration

The parameters of the minesweeper board can be changed within the config.cfg file:

```` text
25 ; Amount of columns
16 ; Amount of rows
50 ; Number of mines on the board
````
